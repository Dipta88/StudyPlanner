# Study Planner – installable web app (PWA)

Android installs this from Chrome, but it must be served over HTTPS.

Easiest free hosting:
- Netlify Drop: go to app.netlify.com/drop, drag this folder in, open the link on your phone.
- or GitHub Pages / Cloudflare Pages.

On the phone: open the link in Chrome > menu (three dots) > Install app (or Add to Home screen).

Your routine is saved on the phone. Updating: change index.html, bump CACHE in sw.js (v10 -> v11), redeploy.
